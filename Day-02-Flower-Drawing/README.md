# Day 02: Turtle Flower Drawing

A colorful flower scene with layered petals, a spiral-patterned center, a curved
stem, leaves, and a starry background. The project uses Python's built-in
`turtle`, `math`, and `random` modules.

## Run

From the repository root:

```bash
python Day-02-Flower-Drawing/main.py
```

The program opens a Turtle graphics window. Close the window to exit.
