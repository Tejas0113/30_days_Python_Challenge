# 30 Days of Python Challenge

A collection of small Python projects, organized one folder per challenge day.

## Day 01: Infinite Rainbow Spiral

The first project draws a continuously rotating rainbow spiral using Python's
built-in `turtle` and `colorsys` modules.

```bash
python Day-01-Infinite-Spiral/main.py
```

No third-party packages are required. See the [Day 01 README](Day-01-Infinite-Spiral/README.md)
for the project details.

## Day 02: Turtle Flower Drawing

A layered flower drawing with a curved stem, visible leaves, and a starry
background.

```bash
python Day-02-Flower-Drawing/main.py
```

See the [Day 02 README](Day-02-Flower-Drawing/README.md) for details.
